### 라이브 검증 내역 (2026-07-04)
- `https://perceptdot.com/` `/terms` `/privacy` `/llms.txt` → 전부 200
- `http://` → 301 → https (정상)
- sitemap.xml 3 URL 정상, robots.txt Googlebot Allow 정상
- robots.txt에 Cloudflare 관리형 Content-Signal 블록 자동 삽입 확인 — 구글 검색 색인에는 영향 없음 (search=yes)

### 알림이 온 이유
사이트 변경 때문이 아니라, 과거에 시작된 "리디렉션 페이지" 유효성 검사가 재확인 시점에 '실패' 상태로 확정되면서 GSC가 정기 알림 메일 발송. 리디렉션은 의도된 것이므로 실패가 정상.
