## 세션 2 (데스크탑 Claude) — eye DOM 기하 검사 4종 추가 · 재측정

CEO 오더: 텍스트 넘침·잘림·고정 배너 가림·요소 겹침 4종 추가 → 같은 50페이지 재측정, 탐지율 80% 이상·오탐 2건 이하면 프로덕션 반영 요청.

### 구현 (`api/src/index.ts` domScript 5~8번, 미배포·미커밋)
- 텍스트 줄(Range.getClientRects) 단위로 검사. 유형별 최대 3건.
- `text_overflow`: overflow visible 블록 밖으로 8px 넘게 삐져나오고, 삐져나온 끝이 실제로 보일 때.
- `clipped_text`: hidden/clip 상자 경계에 줄이 걸려 잘릴 때. ellipsis·line-clamp 제외, 조상이 블록째 잘라내는 캐러셀·미리보기는 제외.
- `fixed_cover`: 첫 화면(scrollY=0)에서 fixed/sticky 요소가 본문 텍스트를 가릴 때. 하단 플로팅(쿠키·채팅), 화면 절반 넘는 모달·로딩 레이어는 제외.
- `element_overlap`: 줄마다 5점을 elementFromPoint로 찍어 남의 불투명 요소가 2점 이상 덮을 때. 접힌 아코디언·sr-only·그라데이션 마스크·같은 글자 효과 레이어 제외. 페이지 전체를 뷰포트 단위로 스크롤하며 검사 후 원위치.
- 심각도: overlap·fixed_cover = high, 나머지 medium.

### 재측정 (같은 50페이지, 로컬 Chromium 1280×800 + 기존 프로덕션 AI 결과 병합)
